## Background 0.1.1

- Uses the directory-compatible plugin ID `background`; the display name remains **Background**.
- Publishes the source, documentation and original demo SVG artwork under **MIT No Attribution (MIT-0)**, copyright 2026 Qiulin Fan.
- Adds matching English and Simplified Chinese guides, using the existing simulated workspace screenshots.
- Adds a checked release workflow that verifies the tag, manifest, package and compatibility versions before attaching exactly `main.js`, `manifest.json` and `styles.css`.

### Install

Download the three attached plugin files to `<vault>/.obsidian/plugins/background/`, restart Obsidian, and enable **Background**. Requires Obsidian Desktop **1.13.7 or newer**. GitHub release availability does not mean the plugin is already listed in the community directory.

### Updating from 0.1.0

The earlier release used the ID `obsidian-background`. Disable that copy, back up its folder, and install this release in `background/`. To preserve image paths and opacity settings, copy the old folder's `data.json` into the new folder locally before enabling it. Keep only one copy enabled. The plugin does not migrate folders or edit your configuration automatically; do not upload `data.json`.

The published 0.1.0 tag and assets are preserved. This release changes packaging and licensing; the wallpaper and opacity implementation is unchanged.
